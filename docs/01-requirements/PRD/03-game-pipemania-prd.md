# PRD-03: 水管工人 (Pipe Mania Game PRD)

## 1. 遊戲願景與簡介 (Overview)
Pipe Mania 是一部經典的網格路徑規劃益智遊戲。玩家在 $10 \times 7$ 的遊戲網格上，利用側邊 5 格 FIFO 佇列產生的水管組件，在化學液體（Flooz）由起點噴發前鋪設一條連續未中斷的管道，使其流經指定長度並安全進入終點排水口。

---

## 2. 核心遊戲機制 (Core Game Mechanics)

### 2.1 網格與元件規格
- **地圖網格**：$10 \times 7$ 離散網格（寬 10 格 x 高 7 格）。
- **13 種水管元件類型 (13 Pipe Types)**：
  1. **7 種基礎管 (Standard Pipes)**：
     - 水平直管 (`─`)、垂直直管 (`│`)
     - 4 款雙向彎管：`╝` (右上)、`╚` (左上)、`╗` (右下)、`╔` (左下)
     - 1 款立體交叉管 (`╬` Cross Pipe)：水平與垂直兩路獨立直行，液體可先後通過兩軸，禁止轉灣。
  2. **4 種單向直管 (One-Way Pipes)**：
     - 僅允許指定單一方向進入（`→`, `←`, `↑`, `↓`）。反向或側邊灌入立即觸發爆管 (Spill Game Over)。
  3. **2 種水庫直管 (Reservoir Tanks)**：
     - 水流進入後填充速度降低至普通直管的 $20\% \sim 33\%$（提供 $3 \sim 5$ 秒緩衝時間），完全填滿後提供大量獎勵分數。
- **障礙與預設元件**：
  - **障礙石頭 (Obstacles)**：不可通過且不可覆蓋替換。
  - **預設固定水管 (Preset Pipes)**：固定於盤面上不可覆蓋，流經獲得額外 Bonus 獎勵分。

### 2.2 5 格 FIFO 水管發牌佇列 (5-Slot FIFO Pipe Queue)
- 側邊 UI 保持顯示 5 格水管。
- 頂端（第 1 格）為當前待放置水管。
- 每次放置後佇列下移補齊，第 5 格依關卡權重動態生成新水管。

### 2.3 發牌權重遞增機制 (Weighted Drop Rate by Level L)
- **$L < 4$**：水庫管發牌率 $0\%$。
- **$L < 7$**：單向管發牌率 $0\%$。
- **$L \ge 7$**：單向管發牌率隨等級線性遞增（最高 $20\%$），水庫管機率隨等級線性遞減（最低 $3\%$），其餘權重平均分配予 7 種基礎管。

### 2.4 無硬編碼線性關卡參數公式 (Linear Level Parameter Formulas)
遊戲支援 1 至 36 關主線關卡，並於通關後進入無限循環模式 (Endless Loop)。難度依以下無硬編碼線性公式計算：

| 關卡參數項目 | 計算公式 (Formula) | 數值範圍 / 單位 | 說明 |
|---|---|---|---|
| **預備起噴時間** | $T_{\text{delay}} = \max(1.0, 10 - 0.25 \times (L - 1))$ | $1.0 \sim 10.0$ 秒 | 開局至液體開始流動的緩衝時間 |
| **每格水流推進速度** | $T_{\text{flow}} = \max(250, 1500 - 35 \times (L - 1))$ | $250 \sim 1500$ 毫秒/格 | 液體在單一水管內的填充推進速度 |
| **通關最低水管長度** | $N_{\text{target}} = \min(40, \lfloor 10 + 0.85 \times (L - 1) \rfloor)$ | $10 \sim 40$ 格 | 進入終點前水流必須通過的最少水管格數 |
| **地圖障礙石頭數量** | $N_{\text{obstacle}} = \min(12, \lfloor 0 + 0.35 \times (L - 1) \rfloor)$ | $0 \sim 12$ 個 | 盤面上隨機生成的障礙石頭 |
| **預設固定水管數量** | $L \ge 5$ 時：$N_{\text{fixed}} = \min(6, \lfloor 1 + 0.15 \times (L - 5) \rfloor)$<br>$L < 5$ 時：$0$ | $0 \sim 6$ 個 | 盤面上預先放置且不可覆蓋的獎勵水管 |

### 2.5 得分與 Fast Forward 加速倍率 (Scoring & Fast Forward)
- **基礎水管填充分**：水流流經每格普通水管 $+50$ 分；十字管/水庫管/預設管 $+100 \sim +300$ 分。
- **水管覆蓋替換扣分**：覆蓋未流經的水管扣除 $-50$ 分。
- **Fast Forward 快進加分**：長按/點擊加速按鈕時，水流推進間隔強制縮短至 $50\text{ ms}$，加速期間流經的每格水管獲得 $2\times$ 額外倍率積分加成。
- **過關結算獎勵**：超過目標長度 $N_{\text{target}}$ 的額外水管，每格獎勵 $+100$ 分。

### 2.6 勝負與溢出失敗判定 (Victory & Spill Game Over Conditions)
- **通關 (Level Complete)**：水流由終點指定合法開口進入，且累積流經格數 $\ge N_{\text{target}}$。
- **未達標失敗 (Underflow Game Over)**：水流進入終點開口，但累積格數 $< N_{\text{target}}$。
- **溢出爆管失敗 (Spill Game Over)**：水流撞擊 $10 \times 7$ 網格外圍邊界、撞上無對接開口之水管/障礙物/單向管反向端。
- **ArcadeBridge 結算**：失敗或 36 關結束時，透過 `ArcadeBridge.emit('GAME_OVER', summary)` 拋出分數與結算資料。
